# ส่งอีเมลยืนยันให้ลูกค้าอัตโนมัติ (จาก office.inspiremarketing@gmail.com)

ระบบจองไม่ส่งอีเมลเอง สคริปต์ `Code.gs` (Google Apps Script) ที่ติดตั้งในบัญชีผู้ส่งจะถามระบบจองทุก 10 นาทีว่า
"ร้านไหนครบเงื่อนไขและยังไม่เคยส่ง" แล้วส่งอีเมล **ร้านละ 1 ฉบับ** จากบัญชีนั้น และแจ้งกลับให้ระบบจดว่าส่งแล้ว (ไม่ส่งซ้ำ)

**เงื่อนไข (ตัวเลือก ก):** ทุกโต๊ะของร้านเป็น "ยืนยันแล้ว" หรือ "ชำระแล้ว" และยอดสลิปที่อ่านแล้วรวมไม่ต่ำกว่าราคา (สลิปที่ถูกปฏิเสธไม่นับ; สลิปใบเดียวจ่ายหลายร้านจะแบ่งตามราคาโต๊ะ)

## สวิตช์ในระบบ (ค่าเริ่มต้น = ปิด)
| โหมด | ผล |
|---|---|
| `off` | ไม่ทำอะไร |
| `dry` | ซ้อม: สคริปต์แสดงรายชื่อที่จะส่ง แต่ **ไม่ส่งจริง** |
| `live` | ส่งจริง |

เปลี่ยนโหมด: SQL `select admin_email_set_mode('dry');` (หรือให้ผู้ช่วยเปลี่ยนให้) ดูสถานะ `select admin_email_status();`
ให้ร้านได้รับอีเมลใหม่: `select admin_email_reset('<shop_key>');` หยุดฉุกเฉิน: ตั้ง `off` หรือกด "removeTrigger" ในสคริปต์

## ติดตั้ง (ทำในบัญชีที่จะเป็นผู้ส่ง ~10 นาที)
1. ล็อกอิน office.inspiremarketing@gmail.com → เปิด https://script.google.com → โครงการใหม่ → วางโค้ดจาก `Code.gs`
2. แก้ส่วน `CONFIG` ด้านบน (ข้อความวันงาน/ช่องทางติดต่อ ถ้ามี) ปล่อยว่างได้
3. Project Settings → Script properties → เพิ่ม 3 ค่า: `SUPABASE_URL`, `SUPABASE_ANON_KEY`, `EMAIL_TOKEN` (ผู้ดูแลระบบให้ค่า)
4. เรียกฟังก์ชัน `run` หนึ่งครั้งด้วยมือ → กดอนุญาตสิทธิ์ (ส่งอีเมล / เชื่อมต่อบริการภายนอก) → ดู Execution log (โหมด dry จะแสดงรายชื่อ ไม่ส่งจริง)
5. เรียก `sendTestToMe` เพื่อส่งอีเมลตัวอย่างเข้ากล่องของคุณเอง ตรวจข้อความ
6. เมื่อพอใจ: ตั้งโหมด `live` แล้วเรียก `installTrigger` (ทุก 10 นาที)

## ข้อจำกัด
- โควตาส่งต่อวัน: บัญชี gmail.com ราว 100 ผู้รับ, Google Workspace ราว 1,500 (สคริปต์เช็กโควตาให้ ที่เหลือส่งวันถัดไป)
- อีเมลที่ส่งแล้วเรียกคืนไม่ได้ และถ้าข้อมูลเปลี่ยนทีหลังจะไม่ส่งซ้ำเอง (ต้อง reset)
- ที่อยู่อีเมลที่รูปแบบผิดจะถูกข้าม (สคริปต์แจ้งใน log) ส่วนที่รูปแบบถูกแต่พิมพ์ผิด (เช่น `gmai.co`) ระบบตรวจไม่ได้ จะตีกลับเข้ากล่องผู้ส่ง
- ยอดสลิปเป็นตัวเลขที่ทีมอ่านจากภาพ ไม่ใช่ยอดที่ธนาคารยืนยัน

## ขั้นตอนแบบ "ร่างก่อน อนุมัติแล้วค่อยส่ง" (ค่าเริ่มต้น `APPROVAL_MODE: true`)
1. เรียก `createDrafts` → สคริปต์สร้าง **ร่างอีเมลใน Gmail** (โฟลเดอร์ Drafts, ป้าย "MAYUCARD6 รออนุมัติ") ร้านละ 1 ฉบับ ยังไม่ส่ง
   (ตัวตั้งเวลา `run` ในโหมดนี้ก็แค่สร้างร่างให้ร้านที่เพิ่งครบเงื่อนไข ไม่เคยส่งเอง)
2. ตรวจ/แก้ร่างใน Gmail ลบร่างที่ไม่ต้องการส่ง
3. เมื่ออนุมัติ แจ้งผู้ดูแลระบบให้ตั้งโหมด `live` แล้วเรียก `sendApprovedDrafts` → ส่งเฉพาะร่างที่ยังอยู่และข้อมูลไม่เปลี่ยนจากตอนสร้างร่าง แล้วบันทึกในระบบ (ไม่ส่งซ้ำ)
4. เริ่มใหม่: `discardDrafts` ลบร่างที่ค้างทั้งหมด แล้ว `createDrafts` ใหม่

## วิธีทำงานปัจจุบัน: แอดมินกดปุ่มรายร้าน (สคริปต์ตัวเดิม `APPROVAL_MODE: false` ใช้ได้เลย ไม่ต้องวางใหม่)
ในหลังบ้าน แดชบอร์ด → "อีเมลยืนยันถึงลูกค้า" มีตารางทุกร้านพร้อมสถานะ และปุ่มต่อร้าน:
- **ส่งอีเมล** = อนุมัติ → สคริปต์ (ตั้งเวลาทุก 1 นาที) ส่งภายใน 1 นาที (ต้องเป็นโหมดส่งจริง)
- **รอตรวจสอบ** = พักไว้ ไม่ส่ง · **ยกเลิกการส่ง** = ไม่ส่งร้านนี้ (กดส่งใหม่ภายหลังได้)
- **ส่งซ้ำ** = ร้านที่ส่งไม่สำเร็จ หรือลูกค้าบอกว่าไม่ได้รับ
- ร้านที่ยังไม่ตัดสินใจ = "พร้อมส่ง" จะไม่ถูกส่งเอง ยกเว้นเปิดสวิตช์ **ส่งอัตโนมัติเมื่อครบเงื่อนไข** (ปิดไว้เป็นค่าเริ่มต้น) ซึ่งจะส่งหลังรอตามเวลาหน่วง (ค่าเริ่มต้น 10 นาที) ร้านที่กดรอตรวจสอบ/ยกเลิกจะไม่ถูกส่งแม้เปิดสวิตช์
- ถ้าร้านหลุดเงื่อนไขหลังอนุมัติ (เช่น โต๊ะถูกเปลี่ยนกลับเป็นรอ) การอนุมัติจะถูกล้าง ต้องกดส่งใหม่
- ปุ่ม **หยุดส่งทั้งหมด** ตั้งโหมดปิดทันที
- เปลี่ยนเวลาหน่วง: `select admin_email_set_delay(15);` (0–120 นาที)
